◆数据与缓存

D1 是权威数据源，IndexedDB 作为实体缓存；localStorage 只保留少量 UI 状态与浏览器本地 AI Secret。

导出文件会移除 GitHub Token、AI API Key 与敏感自定义 Headers，避免把密钥写入备份。
